# Homebrew Tap

Homebrew tap for distributing developer tools and open-source projects.

## Installation

Add the tap:

```bash
brew tap meesakveld/tap
```

Then install a package:

```bash
brew install context
```

## Available packages

| Package                                            | Description                                           |
| -------------------------------------------------- | ----------------------------------------------------- |
| [`context`](https://github.com/meesakveld/context) | Turn your codebase into structured, AI-ready context. |

## Updating

Update the tap and installed packages:

```bash
brew update
brew upgrade
```

## Packages

Each package is maintained in its own GitHub repository. Releases are distributed through this tap as Homebrew formulas.
